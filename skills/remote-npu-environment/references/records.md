# 为重装保存复现材料

每台机器、每套环境分别记录，避免把一台机器的状态套用于另一台。关键材料必须保存在不会随远端重装消失的位置，例如本地任务目录或用户指定的持久存储；仅保存在远端 Home 不算完成备份。

至少保存：

- **连接与机器记录**：机器标识、地址/别名、端口/跳板机、普通用户、工作根目录、公钥指纹、核实日期，以及系统/架构/NPU/驱动信息；不保存密码、令牌或私钥。
- **环境清单**：所属项目/任务标识、环境命名与可识别元信息位置、用户选择依据，Python、uv、PyTorch、torch-npu、CANN/算子包的实际版本、构建标识和环境路径；源码构建记录 commit 和构建步骤。
- **安装材料**：依赖声明、带来源和哈希的锁文件、安装包/镜像地址与校验值、用户配置和激活脚本、按顺序记录的安装命令。需离线恢复或制品可能下架时，保存必要制品到持久存储。
- **验证证据**：执行时间、设备选择、实际命令、日志和未完成项。恢复后重新验证，不沿用重装前的通过结论。

恢复流程为：确认目标机器与版本选择 → 恢复可信 SSH 连接 → 必要时由管理员初始化普通用户 → 核对当前系统与驱动 → 取回复现材料 → 在普通用户目录重建 → 验证并更新记录。
